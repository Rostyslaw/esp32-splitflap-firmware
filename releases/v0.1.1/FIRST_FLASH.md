# Перше встановлення 0.1.1

Цей пакет — для ESP32-S3 із щонайменше 4 MB flash, DIO 40 MHz. Фактичну плату та силові драйвери треба перевірити до підключення двигунів. На фізичній платі цей випуск ще не випробуваний; програмна збірка й тести пройшли.

Для першого запису розпакуйте `first-flash-0.1.1.zip`. `firmware.sfu` призначений лише для подальших оновлень через вебпанель.

У каталозі розпакованого пакета виконайте самостійно, підставивши правильний порт:

```text
python -m esptool --chip esp32s3 --port YOUR_PORT --baud 460800 --after no_reset write_flash --flash_mode dio --flash_size 4MB --flash_freq 40m 0x0 bootloader.bin 0x8000 partition-table.bin 0xf000 ota_data_initial.bin 0x20000 esp32-splitflap-idf.bin
```

Синтаксис сумісний з esptool 4.11.0. Спочатку відкрийте локальну консоль на 115200 бод, потім натисніть Reset на платі. Автоматичний перезапуск у команді вимкнений, щоб не пропустити одноразові дані першого входу. Прошивка виводить їх через UART0 та додаткову USB Serial/JTAG консоль; доступність конкретного USB-роз’єму залежить від плати.

При переході зі старої прошивки спочатку збережіть потрібні старі налаштування. Якщо NVS несумісна/пошкоджена або одноразові дані першого входу втрачено, власник може **явно скинути NVS** командою `python -m esptool --chip esp32s3 --port YOUR_PORT --after no_reset erase_region 0x9000 0x6000`. Це видаляє всі збережені параметри й паролі цього проєкту; не застосовуйте під час звичайного OTA. Відкрийте консоль перед наступним Reset, щоб отримати нові дані входу.

Під’єднайте телефон до `Splitflap-<MAC>`, відкрийте `http://192.168.4.1` і введіть унікальний ключ керування. Установіть час із браузера або налаштуйте Wi-Fi/SNTP. Початково руху немає. Для перших тестів відомі старі канали — розряд3 (Hall6/PCF4–7) і розряд4 (Hall5/PCF0–3); невідомі два Hall не вигадані. Відповідність фізичних позицій можна змінити в панелі.

PCF8575 не живить двигуни: потрібні силові драйвери. Початкова полярність сигналів — активний HIGH зі старого коду. На ввімкненні живлення сам PCF має HIGH; безпечний старт має забезпечувати силова схема.

Повна документація: приватний `Rostyslaw/esp32-splitflap-idf`, README та docs/OTA.md. Під час підготовки цього пакета наведені команди фізичного запису не виконувалися.
